# Aerial Gaia

[English](README.en.md) · [Установка, проверка и откат](docs/GAIAOS.md) · [Устройство и портирование](docs/devices/gaiaos-t950s-be30ae.md)

Форк [Aerial](https://github.com/pengchujin/aerial-tv) для телевизоров GaiaOS / CVTE. Основан на **v1.47**, текущая сборка **1.47-gaia.10** (`versionCode 60`), пакет **`app.orchard.tv.gaia`**. Автор исходного Aerial — pengchujin; исходная лицензия MIT сохранена.

## Обновление 1.47-gaia.10

Добавлена экспериментальная многозадачность для проверенного GaiaOS Android 14: двойной Home открывает плитки запущенных задач поверх обоев лаунчера. Выделение использует тот же компонент, что и док. OK возвращает приложение, ↑ закрывает его задачу, ↓ переводит фокус на ⓘ. Заголовок и подсказки скрыты до нажатия ⓘ; Back сначала закрывает подсказки, затем переключатель.

Помощник запускается с правами ADB shell через локальный ADB после разблокировки пользователя; root не нужен. Автозапуск **выключен по умолчанию**: [включение, ограничения и откат](tools/task-bridge/README.md). VPN, AirPlay и известные системные компоненты защищены от закрытия. Закрытие задачи не равно принудительной остановке всех служб приложения.

На проверенном ТВ подтверждены двойной Home, возврат в приложения, автозапуск после перезагрузки и закрытие задач. После загрузки помощник становится доступен после подключения Wi-Fi. Его расход памяти — около 44 MiB PSS; это экспериментальная функция для совместимых прошивок, а не универсальная поддержка Android TV. HDMI и AirPlay в этом цикле повторно не проверялись.

## Что изменено

- **Direct Boot HOME:** отдельный минимальный стартовый экран доступен до разблокировки пользовательского хранилища. После `USER_UNLOCKED` открывает обычный Aerial. Это позволило проверенному телевизору загрузиться с отключённым Mars.
- **Home:** объявлены категории `HOME` и CVTE `COMMON_HOME`; штатная кнопка ведёт в Aerial Gaia.
- **HDMI:** Droidlogic HW5–HW8 направляются через нативный CVTE TIF player вместо неработающего универсального VIEW intent.
- **Home Guard:** `com.cvte.tv.setting` исключён из перехвата как экран телевизионного входа, иначе HDMI сменяется домашним экраном.
- **Раздельная установка:** отдельный package ID и тип аккаунта восстановления, имя Aerial Gaia во всех пяти локализациях.

Это приложение, **не прошивка**. Оно не удаляет и не отключает системные пакеты автоматически. AirPlay работает отдельным приёмником; сам лаунчер не реализует протокол AirPlay.

## Проверено на устройстве

LVG 32LM57, плата TP.T950ST.PB752, `t950s_be30ae`, Android 14, прошивка `20250715_151455`, 1 GB RAM / 8 GB storage.

На 1.41-gaia.3, 24 октября 2026: перезагрузка с Mars `installed=true, hidden=true, enabled=3`, без процесса Mars; Direct Boot → обычный Aerial; затем пользователь подтвердил HDMI1 (изображение/звук), физические Home/стрелки/OK/Back и AirPlay.

Другие платы, версии прошивки, HDMI2–4, CEC и длительное использование без Mars **не проверены**. Одинаковое название GaiaOS не гарантирует совместимость. Не отключайте Mars до проверки Direct Boot и готового сетевого отката: прежняя сборка зависала на Wisdom Share, Wi-Fi не поднимался; восстановление удалось через Ethernet.

## Сборка

JDK 17, Android SDK 36 и Gradle Wrapper из репозитория:

```sh
./gradlew -Pgaia assembleStandardRelease
```

APK: `app/build/outputs/apk/standard/release/app-standard-release.apk`. Флаг `-Pgaia` обязателен; guard-вариант без HOME здесь не является заменой standard.

Для постоянной подписи задайте `local/signing.properties` и собственный keystore в `local/`:

```properties
storeFile=signing.keystore
storePassword=YOUR_STORE_PASSWORD
keyAlias=YOUR_ALIAS
keyPassword=YOUR_KEY_PASSWORD
```

Не публикуйте ключи. Без них upstream-конфигурация использует локальный debug key. Обновление поверх установленной Gaia требует **той же подписи**; при несовпадении остановитесь, не удаляйте приложение ради установки.

## Установка и обновления

Следуйте [GaiaOS-инструкции](docs/GAIAOS.md). Upstream `tools/install.sh`, `restore.sh`, сайт и встроенные уведомления о новых версиях относятся к исходному Aerial. **Не используйте их как установщик/обновлятор Gaia.** Автоматический канал Gaia пока не реализован; используйте сборку с сохранёнными патчами и той же подписью.

Обновление не должно заменять проверенный код последней upstream-версией без повторной проверки Direct Boot, HOME, HDMI и AirPlay. Исходные материалы upstream в `docs/`, `site/` и `tools/` сохранены для истории; для этого форка приоритетны эта страница и `docs/GAIAOS.md`.
