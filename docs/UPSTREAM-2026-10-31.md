Kept unchanged: package/signature identity, DirectBootHomeActivity, boot settings,
CVTE and MediaTek HDMI adapters, channel catalogue/player, task switcher, AirPlay,
VPN/LAN handling, weather localization, native settings and .53 night panel route.
The ADB interface uses the existing permission-guarded receiver, not a listener.

Deferred: #958 network icon/short-press behavior (preserve our separate VPN status
and native network UI), draft #1066 viewport clipping (needs physical focus and
scroll validation), frame-capture/playback rewrites and #945 launch transitions
(need separate adaptation to our task switcher and problematic CVTE video plane).
Clash and background cleaning are not included. #962's cold-start performance
benefit is a hypothesis to measure on our TVs, not a measured claim for this port.

Validation: 156 standard release unit/Robolectric tests passed, release APK and
vital lint built successfully. Shell helper checked with bash -n and an offline
ADB stub. The release signature must match the previous local certificate.
No TV installation, reboot, package changes or APK release publication is part
of these two code pushes. Hardware navigation, HDMI, tasks, night mode and
performance comparison remain the next acceptance step.
